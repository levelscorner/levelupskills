# B2B Sales Discovery and Pipeline

## Overview
Use this skill to build a cleaner B2B sales process: how opportunities are qualified, how discovery is run, how next steps are earned, and how pipeline health is interpreted. The goal is not to sound salesy. The goal is to learn fast and move real deals forward.

## When to Use
Use this skill when the main problem is **sales-process execution**.

Typical triggers:
- discovery calls are vague or inconsistent
- pipeline stages are muddy
- qualification is weak
- objections are recurring but poorly handled
- opportunities stall after meetings
- the team wants a more repeatable sales process

Do **not** use this as the main skill when:
- the issue is founder-specific role in selling → use `founder-sales-for-b2b`
- the issue is post-sale adoption or renewals → use `customer-success-for-b2b`
- the issue is broad GTM experimentation rather than pipeline mechanics → use `gtm-and-growth-experiments`

## Core Principle
A strong B2B sales process reduces wasted time by quickly clarifying whether the prospect has a real problem, real urgency, and a believable path to action.

## Always cover
- ICP and qualification logic
- discovery structure
- objection patterns
- next-step discipline
- pipeline stages and exit criteria
- measurement of pipeline quality

## Workflow
1. Identify product type, buying motion, and target account profile.
2. Diagnose the main failure point: qualification, discovery, follow-up, objections, or stage discipline.
3. Recommend a cleaner call structure and opportunity-management process.
4. Define pipeline stages, stage exits, and next-step rules.
5. Tie sales behavior to learning, not just activity volume.

## Output format
Return:
1. pipeline diagnosis
2. recommended discovery and qualification structure
3. objection and follow-up guidance
4. stage logic and metrics
5. next improvements to test

## Common pitfalls
1. **Treating every interested conversation as pipeline.** Curiosity is not a deal.
2. **Ending calls without a real next step.** Momentum dies in vagueness.
3. **Using qualification as a script instead of judgment.** Process should sharpen thinking.
4. **Tracking stage counts without stage quality.** A full pipeline can still be weak.
5. **Talking too much and learning too little in discovery.** Good discovery uncovers the buying problem.

## Verification checklist
- [ ] I defined the core pipeline failure point.
- [ ] I included qualification, discovery, and next-step logic.
- [ ] I clarified stage exits or movement rules.
- [ ] I tied recommendations to pipeline quality, not just activity.

## Examples
### Example: stalled pipeline
Return:
1. The pipeline issue is not top-of-funnel alone; deals are not advancing with commitment.
2. Tighten stage criteria and require explicit next-step ownership.
3. Improve discovery around urgency, stakeholders, and current workaround.
4. Track conversion by stage quality, not just number of calls.
5. Remove soft opportunities from the main forecast view.

### Example: weak discovery calls
Return:
1. Discovery is too product-led and not problem-led.
2. Reframe the call around current process, pain, consequence, and decision dynamics.
3. Use objections as diagnostic signals, not closing battles.
4. End each call with a concrete mutual next step or disqualify cleanly.
5. Review recordings for repeated gaps.
