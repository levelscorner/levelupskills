# GTM and Growth Experiments

## Overview

Use this skill to design go-to-market learning rather than random marketing activity.

## Core Principle

Early growth is usually a discovery problem before it is a scale problem.

## Workflow

1. Clarify ICP, problem, and buying context.
2. Define the value proposition and core message.
3. Select a small number of channels to test.
4. Design experiments with clear success and failure criteria.
5. Turn results into next-step decisions.

## Always cover

- ICP clarity
- message-market fit
- channel assumptions
- experiment design
- conversion steps
- metrics and learning loop

## Output format

Return:
1. positioning summary
2. channel hypotheses
3. experiment plan
4. metrics to track
5. next recommendation

## Common pitfalls

- too many channels at once
- vague success criteria
- mistaking reach for learning
- marketing before message clarity

## Verification checklist

- [ ] I defined the ICP and message clearly.
- [ ] I recommended focused experiments.
- [ ] I tied metrics to learning, not vanity.
