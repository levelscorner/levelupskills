# Brand Positioning and Messaging

## Overview
Use this skill to shape how a company is understood, remembered, and chosen. The point is not prettier copy. The point is sharper market meaning.

## When to Use
Use this skill when the main problem is **message-market clarity**.

Typical triggers:
- unclear positioning
- weak differentiation
- muddy category story
- inconsistent value narrative
- brand voice that does not match product truth
- messaging that feels generic or interchangeable

Do **not** use this as the main skill when:
- the task is mostly copy polish or formatting
- the task is channel strategy or growth experiments → use `gtm-and-growth-experiments`
- the task is an internal founder/status update → use `founder-communication-and-updates`

## Core Principle
Good positioning reduces cognitive load for the customer. It makes the right buyer understand what the product is, why it matters, and why it is meaningfully different.

## Always cover
- audience and context
- problem framing
- differentiation logic
- value narrative
- proof and credibility
- messaging risks

## Workflow
1. Clarify audience, use case, category context, and alternatives.
2. Diagnose whether the issue is weak positioning, muddy messaging, poor differentiation, or inconsistent voice.
3. Separate core market meaning from channel-specific copy.
4. Recommend a sharper narrative structure anchored in product truth.
5. Suggest what to test next in language, proof, or framing.

## Output format
Return:
1. positioning diagnosis
2. recommended narrative / message architecture
3. differentiation and proof points
4. tone / voice guidance
5. next messaging tests

## Common pitfalls
1. **Confusing slogan quality with positioning quality.** Better phrasing cannot fix unclear value.
2. **Copying category language from competitors.** That often erases differentiation.
3. **Making claims without proof cues.** Messaging needs credibility, not just aspiration.
4. **Trying to sound premium, technical, and friendly all at once.** Voice needs coherence.
5. **Targeting everyone.** Positioning gets weak when the audience is too broad.

## Verification checklist
- [ ] I identified the audience and alternative choices clearly.
- [ ] I separated strategic positioning from copy-editing.
- [ ] I named the true differentiation, not just generic benefits.
- [ ] I recommended concrete message tests or proof improvements.

## Examples
### Example: positioning diagnosis
Return:
1. Audience is clear, but category framing is muddy.
2. The product sounds like a generic AI tool rather than a workflow product.
3. Strongest proof point is time-to-output reduction.
4. Messaging should move from feature list to workflow outcome.
5. Test one sharper category line and one proof-led homepage version.

### Example: tone guidance
Use a voice that is:
- clear over clever
- specific over inflated
- confident without hype
